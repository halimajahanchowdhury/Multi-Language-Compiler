# Multi-Language Compiler

A Compiler Construction Lab project focused on developing a compiler for processing source code written in C, C++, and Java.

## Objectives
- Perform lexical and syntax analysis.
- Perform semantic analysis.
- Generate an intermediate representation of the source code.
